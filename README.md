## 📋 Coursework & Lab Index

This repository contains the complete laboratory practicals, programs, and interactive implementations across 6 core modules:

### 1. HTML5 Fundamentals (`/html/`)
- Basic HTML page structure, semantic tags, and headings (`<h1>`-`<h6>`).
- Nested ordered, unordered, and definition lists.
- Tables with cell padding, cell spacing, `colspan`, and `rowspan` (Academic timetable layouts).
- Forms and input validations with text, email, date, radio, checkbox, dropdown, and submit controls.
- Audio and video embeds, iframes, and responsive layouts.

### 2. CSS3 Styling & Layouts (`/css/`)
- CSS selectors (class, id, attribute, pseudo-classes, and pseudo-elements).
- CSS Box Model: margins, borders, padding, and content sizing.
- Modern layout systems: CSS Flexbox (1D) and CSS Grid (2D).
- Transitions, hover effects, CSS animations, and dark mode styling.
- Real-world UI components: KPI cards, navbar menus, pricing tables, and responsive forms.

### 3. JavaScript Programming (`/javascript/`)
- Core logic: Factorial, Fibonacci series, Prime number check, Palindrome, and Armstrong numbers.
- DOM manipulation and event handling (click, change, input, mouseover).
- Client-side form validation using regular expressions (Email, Password, Phone Number).
- Web Storage API (`localStorage` & `sessionStorage`).
- Interactive mini-applications:
  - Digital Calculator
  - Stopwatch & Countdown Timer
  - To-Do List Application
  - Interactive Quiz App
  - Weather App Interface
  - Tic-Tac-Toe Game

### 4. MySQL Database Practical (`/mysql/`)
- **DDL**: Database creation, table creation with constraints (`PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `CHECK`).
- **DML**: `INSERT`, `UPDATE`, `DELETE`, and `SELECT` queries.
- Filtering and sorting with `WHERE`, `ORDER BY`, `GROUP BY`, and `HAVING`.
- Relational Joins (`INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL JOIN`).
- Stored procedures, triggers, and transactional queries.

### 5. Node.js & Express (`/nodejs/`)
- Built-in HTTP server, File System (`fs`), and path manipulation.
- Express.js server setup with routing and middleware.
- REST API implementation (GET, POST, PUT, DELETE).
- User authentication and JSON Web Token (JWT) handling.

### 6. Supabase Integration (`/supabase/`)
- Cloud PostgreSQL database connection.
- Database tables, schema creation, and foreign keys.
- Row-Level Security (RLS) policies and authentication.
- Real-time event listeners and data storage.

## 📌 Coursework Overview

This repository contains a production-grade, interactive Web Technology Laboratory portal covering the complete front-end and full-stack coursework. Every experiment includes:
- **Interactive Live Preview**: Test and interact with the UI, logic, SQL queries, or APIs directly in the browser.
- **Complete Formatted Source Code**: Syntax-highlighted HTML, CSS, JavaScript, SQL, and Node.js code blocks.
- **One-Click Clipboard Copying**: Instant code copying for lab documentation.
- **Bi-directional Navigation**: Seamlessly navigate through all programs using previous/next controls.

## 📂 Laboratory Modules & Syllabus Breakdown

### 1. HTML5 Fundamentals (`/html/`)
- **Core Elements**: Semantic tags, headings (`<h1>`-`<h6>`), paragraphs, formatting, and character entities.
- **Lists & Tables**: Ordered, unordered, definition lists, complex nested tables with `rowspan` and `colspan`.
- **Media & Embedded Content**: Audio players, HTML5 video containers, external embeds, and iframes.
- **Forms & Inputs**: Registration forms, client-side input validations, modern HTML5 input types (`date`, `color`, `range`, `email`, `tel`).
- **Real-World Layouts**: College academic timetables, conference registration portals, and responsive personal portfolios.

### 2. CSS3 Styling, Flexbox & Grid (`/css/`)
- **Selectors & Specificity**: Element, class, ID, attribute, and combinator selectors (`+`, `~`, `>`, descendant).
- **Box Model & Layout**: Margins, paddings, borders, box-sizing, and display modes.
- **Modern Flexbox & CSS Grid**: 1D Flexbox alignment, 2D Grid layouts with auto-fit, minmax, and area templates.
- **Design Systems & Animations**: Transitions, keyframe animations, CSS custom properties (variables), and dark mode theming.
- **SaaS Component Library**: KPI metric cards, responsive pricing tables, modal dialogs, sliding drawers, and administrative dashboard layouts.

### 3. JavaScript Programming & Interactive Web Apps (`/javascript/`)
- **Algorithmic Programs**: Prime numbers, Fibonacci series, factorial, Armstrong numbers, palindromes, and array manipulation.
- **DOM & Event Handling**: Dynamic table CRUD, character counters, dependent dropdowns, mouse/keyboard listeners, and event bubbling/delegation.
- **Form Validation**: Comprehensive regular expression validation for emails, passwords, and phone numbers with real-time feedback.
- **Browser APIs & Storage**: `localStorage` and `sessionStorage` CRUD, Geolocation API, and Fetch API.
- **Interactive Mini-Projects**:
  - 🧮 Digital Calculator
  - ⏰ Digital Clock & Stopwatch
  - ⏳ Countdown Timer
  - ✅ To-Do List with persistent storage
  - 🌦️ Weather Forecast Dashboard
  - 🧠 Interactive Quiz Application
  - 🔢 Number Guessing Game
  - ❌ Tic-Tac-Toe Game with AI / 2-Player modes
  - 📊 Student Grade & Marks Calculator
  - 🔐 Secure Password Generator
  - ⚖️ BMI Health Calculator

### 4. MySQL Database Engineering (`/mysql/`)
- **DDL Operations**: Schema creation, table definitions, primary keys, foreign keys, and constraints (`CHECK`, `DEFAULT`, `NOT NULL`).
- **DML & Advanced Queries**: `INSERT`, `UPDATE`, `DELETE`, `SELECT` with `WHERE`, `ORDER BY`, `GROUP BY`, and `HAVING`.
- **Relational Joins**: `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `CROSS JOIN`, and self-joins.
- **Subqueries & Views**: Correlated subqueries, inline views, and virtual tables.
- **Stored Procedures & Transactions**: PL/SQL stored procedures, parameter modes (`IN`, `OUT`), triggers, and ACID transactions (`COMMIT`, `ROLLBACK`).
- **Interactive SQL Terminal**: Execute queries with live execution times and tabular results.

### 5. Node.js & Backend Architecture (`/nodejs/`)
- **Core Node.js**: Built-in `http`, `fs`, `path`, and `events` modules.
- **Express.js Framework**: REST API endpoints, routing architecture, and JSON body parsing.
- **Middleware Pipeline**: Custom logging middleware, error handling, CORS headers, and request rate limiters.
- **Authentication & Security**: JSON Web Tokens (JWT) creation, token verification, and role-based access control.
- **Full-Stack REST CRUD**: Complete backend implementation for student and course management.

### 6. Supabase Cloud Integration (`/supabase/`)
- **Database Tables**: Cloud-hosted PostgreSQL table schemas, foreign key relationships, and data indexing.
- **Supabase JavaScript Client**: Connecting to Supabase, querying tables, and handling relational joins.
- **Authentication & Row Level Security (RLS)**: User sign-up, sign-in, session tokens, and strict database security policies.
- **Realtime & Storage**: Cloud file bucket uploads and live Postgres change listeners.

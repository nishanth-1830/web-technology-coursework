Responsive Webpage Using CSS Media Queries

Implements responsive layout that gracefully adapts between desktop (3 columns), tablet (2 columns), and mobile (single column) using @media rules.

Responsive Design

Working Demonstration / Output

● Live Execution

Media Queries In Action

Resize your browser window or view in mobile device mode to observe dynamic column reconfiguration and background shifts.

Desktop View

When viewport > 768px: Displays three columns side-by-side.

Tablet View

When viewport ≤ 768px: Reconfigures to 2 columns with soft blue background.

Mobile View

When viewport ≤ 480px: Stacks into a single column with warm yellow highlight.
